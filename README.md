

## 📌 Описание

**Путеводитель по достопримечательностям/музеям** — это Android-приложение, написанное на **Kotlin**, которое демонстрирует работу с модульной архитектурой и использует отдельную библиотеку `weatherlib` для обработки данных о погоде или других внешних источников (например, API). Основная цель проекта — показать структуру Android-приложения с разделением на модули и реализацию бизнес-логики в отдельной библиотеке. ([GitHub][1])


## 🧰 Стек технологий

Проект написан с использованием следующих технологий:

* 🟣 **Kotlin** — основной язык разработки. 
* 🤖 **Android SDK** — для создания мобильного приложения.
* ⚙️ **Gradle / KTS** — система сборки проекта. 
* 📦 Модульная структура с выделением отдельной библиотеки (`weatherlib`).
